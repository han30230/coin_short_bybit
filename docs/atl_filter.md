# 전체 이력 ATL 기반 숏 진입 제한

1번 Binance 급등숏과 3번 Bybit 급등숏에만 적용합니다. 기본 ON, 배수는 1.3입니다.
2번 ST 롱·숏 저장소는 변경하지 않습니다.

## 기준

- ATL은 **현재 거래소 선물 계약의 상장일부터 현재까지 전체 일봉 저가 최솟값**입니다.
- 코인 자체의 다른 거래소·현물 상장 이전 이력은 포함하지 않습니다.
- 현재가가 `ATL × 1.3` **이하이면** 신규/추가 숏 주문을 만들지 않습니다.
- 예: ATL 100 → 현재가 130 이하는 차단, 130 초과에서만 다른 조건을 계속 확인합니다.
- 기존 포지션 청산, 익절, 체결 확인은 이 필터를 통과할 필요가 없습니다.

## 수집 및 검증

최초 숏 진입 시도가 발생하면 별도 작업 스레드에서 전체 이력을 수집합니다.
확인 중에는 주문을 보류합니다. 최근 N일로 대체하지 않습니다.

1. exchangeInfo의 onboardDate / instruments-info의 launchTime을 UTC 일자로 내립니다.
2. 상장일부터 오늘까지 최대 1,000일씩 나누어 모든 일봉을 요청합니다.
3. 첫날·마지막 날·중간 날짜가 하나라도 누락되거나, 중복/잘못된 OHLC가 있으면 사용하지 않습니다.
4. 전체 범위를 검증했을 때만 ATL을 사용하고 결과를 원자적으로 저장합니다.
5. 다음 갱신은 직전에 수집한 마지막 날짜부터 겹쳐 요청합니다. 과거 최저가는 유지합니다.
6. 값은 최대 60초 동안 유효합니다. 갱신 대기·실패 중에는 신규/추가 진입을 보류합니다.
7. 최신 현재가 자체가 새 최저가라면 즉시 차단합니다.

상장 시각을 알 수 없거나 API가 전체 이력을 제공하지 않는 종목은 **진입하지 않습니다**.
메타데이터보다 실제 거래가 늦게 시작했거나 거래 중단으로 일봉이 빠진 경우에도 보수적으로 차단합니다.
상장 메타데이터가 잘못되어 있거나 거래소가 과거 OHLC를 사후 정정한 경우까지 정확성을 보장하지 않습니다.
과거 이력 정정/단위 변경 시 봇을 멈추고 캐시를 삭제해 전체 이력을 재검증하세요.

## 설정

```dotenv
ATL_FILTER_ENABLED=true
ATL_ENTRY_MULTIPLIER=1.3
# 계정/프로세스별 별도 파일을 권장
# ATL_CACHE_FILE=atl_cache.json
```

캐시에는 거래소·환경·상장 시각·검증 구간을 기록하며 다른 기준의 캐시는 사용하지 않습니다.
기본 캐시는 프로젝트 폴더의 atl_cache.json이고 Git에서 제외됩니다.
오류/확인 중인 ST 진입 신호는 소모하지 않아, 다음 루프에서 조건을 다시 검사할 수 있습니다.
신규 주문 생성 전에 평가하며, 이미 거래소에 접수된 지정가 주문을 취소하는 기능은 추가하지 않습니다.

## 검증 범위

테스트는 2,101일의 전체 이력, 오래된 최저가, 경계값, 누락·중복·잘못된 가격,
캐시/재시작/날짜 전환, API 실패, 비동기 수집, 신규·추가 주문 차단, ST 신호 보존을 포함합니다.
개발 환경의 네트워크 제한으로 실거래소 전체 이력 수집을 검증하지 못했습니다.
실제 주문을 내는 실거래 테스트도 수행하지 않았습니다.
